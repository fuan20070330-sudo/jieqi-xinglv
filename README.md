# 节气行旅：二十四节气的物候解谜

**米兰设计周「触摸时间·魅力节气」C 类数字艺术 · 浏览器平面探索游戏**

- 在线试玩：https://fuan20070330-sudo.github.io/jieqi-xinglv/
- 作品形态：四季俯视角 2D 探索游戏，纯前端、无后端、无外部 AI API
- 操作：WASD / 方向键移动，E / 空格互动；手机端使用虚拟摇杆与“行 / 往”按钮
- 内容规模：4 张季节地图 × 每季 6 个节气碑 = 24 个习俗小游戏
- 玩法差异：24 个小游戏使用 24 种不同操作机制，不复用同一套小游戏模板
- 教程规则：进入小游戏先阅读教程，点击“确定，开始”后才计时与互动
- 星级规则：每关只保存最佳星级，重玩不累加；每季 18 星，超过 2/3（至少 13 星）才能通过“往”星门
- 技术：HTML5 Canvas、CSS3、原生 JavaScript、localStorage；无第三方运行时
- AI 辅助设计：代码、文案、版面与测试脚本使用 AI 协助生成初稿，学生完成修改、文化核验与实际验收；AI 不参与游戏运行

## 游戏定位

玩家控制一名小小节气观察员，在春、夏、秋、冬四张明亮地图中自由行走。靠近节气碑后进入与该节气习俗有关的小游戏，完成挑战、获得星级，并修复被云雾遮住的四季时间秩序。

作品不是“节气展示页 + 答题积分”，而是一套可移动、可触屏、可重玩、带教程、星级、章节门槛和本地存档的浏览器游戏。

## 四季地图

- **春之章 · 雨生**：嫩绿田野、春雨、花瓣与粉色花树。
- **夏之章 · 长明**：明亮稻田、河渠、烈日、热浪与向日葵色。
- **秋之章 · 丰收**：金色田埂、柿树、河灯与旋转落叶。
- **冬之章 · 瑞雪**：冰蓝雪地、冰面、雪松与多层飘雪。

每季的地图色、天气粒子、节气碑和 HUD 主题会一起切换。

## 24 个节气习俗小游戏

### 春

1. **立春 · 咬春**：左右移动竹篮，接春饼、萝卜与韭黄，避开石块和枯枝。
2. **雨水 · 占稻色**：观察谷粒符号亮起顺序并复现。
3. **惊蛰 · 蒙鼓皮**：在节拍环收拢时击鼓。
4. **春分 · 竖蛋**：在绿色时机区停下游标，让鸡蛋站稳。
5. **清明 · 放纸鸢**：将风筝面、竹骨、飘带和线轴拖到正确轮廓，拼成纸鸢。
6. **谷雨 · 谷雨茶**：把单芽、一芽一叶与杂质分入正确茶篓。

### 夏

1. **立夏 · 斗蛋**：左右瞄准对手蛋，点击碰撞赢下三局。
2. **小满 · 祭车神**：左右交替踩踏水车踏板，把水灌进田里。
3. **芒种 · 收种忙**：从秧盘拖出秧苗，栽满九块水田格。
4. **夏至 · 夏至面**：按住面头，沿碗中虚线拖出完整面条。
5. **小暑 · 晒书衣**：观察天空变化，在“晒”与“收”之间连续判断。
6. **大暑 · 送大暑船**：左右掌舵，收集福灯并避开河石。

### 秋

1. **立秋 · 晒秋**：把红、黄两色作物拖到同色晒架。
2. **处暑 · 放河灯**：点击左右河岸改变水流，把河灯推过礁石。
3. **白露 · 收清露**：在露珠消失前逐颗点入瓷盅。
4. **秋分 · 祭月**：旋转三层月纹礼盘，让刻度全部归位。
5. **寒露 · 登高赏菊**：从低到高依次点击石阶，登上山亭。
6. **霜降 · 摘柿子**：按住树干左右摇动，收满五颗柿子。

### 冬

1. **立冬 · 包饺子**：按住面皮向右折合，捏出三只饺子。
2. **小雪 · 腌腊肉**：按住盐罐在肉条上停留，均匀覆盖盐粒。
3. **大雪 · 扫雪开路**：拖动扫帚清除雪堆，打开归家道路。
4. **冬至 · 搓汤圆**：按住面团画圈，把三颗汤圆搓圆。
5. **小寒 · 腊八粥**：按米、豆、枣、果的顺序把食材拖进粥锅。
6. **大寒 · 除尘迎年**：快速来回划动，清理屋内尘团。

## 游戏系统

- 小游戏必须先阅读教程，点击“确定，开始”后才开始计时和接受输入。
- 每关按失误数获得 1—3 星；每关只保存历史最佳星级与最佳成绩，重玩不累加。
- 每季 6 关全部完成，且本季星数超过 18 星的 2/3（至少 13 星），才可开启地图上的“往”星门。
- 移动端靠近星门后，右下角按钮会从“行”变为“往”；桌面端也可直接点击底部提示进入。
- localStorage 保存关卡完成状态、最佳星级、最佳成绩、当前季节、章节庆祝状态和声音设置。
- 刷新页面后可以继续；单文件离线版同样支持本地存档。

## 运行

### 目录版

直接打开 `index.html`，或启动本地静态服务器：

```powershell
py -m http.server 8770 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8770/`。

### 单文件离线版

```text
output/节气行旅_离线版.html
```

重新构建：

```powershell
node build-offline.mjs
```
