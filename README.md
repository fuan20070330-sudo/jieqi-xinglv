# 节气行旅：二十四节气的物候解谜

**米兰设计周「触摸时间·魅力节气」C类数字艺术 · 四季俯视探索小游戏**

- 在线演示：https://fuan20070330-sudo.github.io/jieqi-xinglv/
- 运行方式：电脑或手机浏览器；无需登录、后端、外部 AI API 或专用硬件
- 操作：WASD / 方向键移动，E / 空格与节气碑互动；手机端使用虚拟摇杆与互动按钮
- 内容规模：4 个季节地图 × 每季 6 个节气习俗小游戏 = 24 个关卡
- 技术：HTML5 Canvas、原生 JavaScript、CSS3；无第三方运行时库
- AI 辅助设计：代码、文案、版面与测试脚本使用 AI 协助生成初稿，学生完成修改、科学核验与验收；AI 不参与游戏运行

## 游戏定位

《节气行旅》是一款明亮的俯视角 2D 探索游戏。玩家控制一名小小节气观察员，依次走进春、夏、秋、冬四张地图，在 24 个节气碑前体验与该节气习俗有关的小游戏。

它不是文字答题页：玩家需要实际走动、靠近节气碑、进入小游戏，并通过收集、节奏、时机、分类、行进或顺序记忆来完成习俗挑战。

## 四季与天气

- **春之章 · 雨生**：细雨、花瓣、嫩绿田野与春分竖蛋、清明纸鸢等习俗。
- **夏之章 · 长明**：烈日、热浪、稻田间的小路与大暑送船、小满水车等习俗。
- **秋之章 · 丰收**：金风、落叶、柿树与秋分祭月、处暑河灯等习俗。
- **冬之章 · 瑞雪**：飘雪、冰面、松树与冬至汤圆、大寒扫尘等习俗。

每季场景使用独立主色和季节色板，顶部 HUD 会随季节切换到对应的明亮配色。

## 24 个习俗小游戏

### 春

1. 立春 · 咬春：收集春饼、萝卜、韭黄。
2. 雨水 · 占稻色：记住并复现谷粒符号顺序。
3. 惊蛰 · 蒙鼓皮：跟随节拍击鼓。
4. 春分 · 竖蛋：在绿色时机区停下，让鸡蛋站稳。
5. 清明 · 放纸鸢：操控纸鸢穿过柳梢并收集彩带。
6. 谷雨 · 谷雨茶：收集嫩叶与茶芽，避开杂草。

### 夏

1. 立夏 · 斗蛋：抓准碰蛋时机。
2. 小满 · 祭车神：按节拍踩动水车。
3. 芒种 · 收种忙：把作物分入“收”与“种”。
4. 夏至 · 夏至面：按顺序完成做面步骤。
5. 小暑 · 晒书衣：把书、衣、谷物分到对应晒架。
6. 大暑 · 送大暑船：左右掌舵，收集福灯并避开河石。

### 秋

1. 立秋 · 晒秋：按红、黄两色分拣秋收作物。
2. 处暑 · 放河灯：护送河灯并收集心愿。
3. 白露 · 收清露：移动瓷盅接住晨露。
4. 秋分 · 祭月：记住并复现供品顺序。
5. 寒露 · 登高赏菊：跟随节拍踏阶登高。
6. 霜降 · 摘柿子：在正确时机摘取红柿。

### 冬

1. 立冬 · 包饺子：按顺序完成包饺子步骤。
2. 小雪 · 腌腊肉：把材料分入“腌制”与“晾晒”。
3. 大雪 · 扫雪开路：在雪径中收集柴火并避开冰窟。
4. 冬至 · 搓汤圆：接住糯米团与馅料。
5. 小寒 · 腊八粥：记住下料顺序并复现。
6. 大寒 · 除尘迎年：收集尘团与旧纸，避开易碎摆设。

## 游戏系统

- 接近发光节气碑时出现互动提示。
- 完成小游戏获得 1—3 星，并记录最佳成绩。
- 每季 6 个节气碑全部完成后，解锁下一季。
- 四季节气碑全部完成，进入“四季行旅”通关画面。
- localStorage 保存小游戏完成状态、星级、最佳成绩、当前季节和章节庆祝状态。
- 单文件离线版可直接双击运行，无网络请求。

## 运行

### 目录版

直接打开 `index.html`，或启动本地静态服务器：

```powershell
py -m http.server 8770 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8770/`。

### 单文件离线版

```text
output/节气行旅_离线版.html
```

重新构建：

```powershell
node build-offline.mjs
```
