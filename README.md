# 节气行旅：二十四节气的物候解谜

**米兰设计周「触摸时间·魅力节气」C类数字艺术 · 纯前端浏览器 2D 数字游戏**

- 赛项主题：触摸时间·魅力节气
- 作品类别：C. 数字艺术类——数字游戏作品（浏览器 2D 游戏，不涉及 VR/AR 与专用硬件）
- AI 辅助设计：代码、文案、版面与测试环节使用 AI 辅助，学生完成修改与验收
- 运行方式：电脑或手机浏览器；无登录、无后端、无外部 AI API
- 核心闭环：**观天 → 识候 → 辨误 → 修复**
- 内容规模：24 个节气关卡、72 候图鉴、4 个章末综合试炼
- 运行依赖：HTML5、CSS3、原生 JavaScript、SVG、Canvas；无第三方运行时库
- 在线演示：https://fuan20070330-sudo.github.io/jieqi-xinglv/

## 一句话定位

《节气行旅》是一款以“修复四季时钟”为目标的浏览器 2D 解谜游戏：玩家通过校准太阳黄经仪、重组七十二候、校准证据天平并修复物候因果链，逐关恢复二十四节气的运行秩序。作品从中国人对时间、自然与生命节律的理解切入，把“时间”转化为可触摸、可推理、可修复的仪器机制。

## 与《时间之书》的区别

本项目不是科普长页、节气卡片集或答题网页，而是关卡制游戏：

1. 每关以一台“时轮仪器”组织四个操作阶段，具有目标、操作、即时反馈、失败重试、成功条件与评分。
2. 核心机制包括旋转黄经仪、混合候牌筛选与排序、双槽证据链、四段因果链修复。
3. 地图采用章节星图与节点解锁；存在连击、精度、时轮分、星级、章末印记和最佳成绩。
4. 72 候作为可收集图鉴；错题进入“证据回廊”复盘。
5. 进程存档可刷新续玩，通关后由 Canvas 生成无身份信息的 PNG 成果卡。

节气科学数据参考了公开通行资料与既有项目背景，但页面结构、交互模型、状态机、美术语言与游戏反馈均为本项目重新设计。

## 运行

### 目录版

直接打开 `index.html` 可使用核心功能。若要进行本地浏览器测试，可在项目目录启动静态服务器：

```powershell
py -m http.server 8770 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8770/`。

### 单文件离线版

直接双击：

```text
output/节气行旅_离线版.html
```

单文件版将 CSS、24 节气数据、天文算法与游戏逻辑全部内联，不请求外部网络资源。

## 操作

- 观天：拖动黄经滑杆、点击 `− / ＋`，或聚焦滑杆后使用键盘方向键。
- 识候：点击选择三枚候牌，再按初候、二候、三候顺序放入观察槽。
- 辨误：从四条材料中选出两条证据。
- 修复：依次点击事件牌，按“太阳位置 → 直射与昼夜 → 地表响应 → 物候表现”排列。
- 手机端所有主要按钮保持可触控尺寸；页面锁定横向溢出。

## 评分

- 每关四段，每段基础分 250；章末试炼每段基础分约 334。
- 最终得分受当前精度影响，满分 1000。
- 错误扣 8% 精度并中断连击；使用一次提示扣 5%。
- 900 分及以上为三星，760 分及以上为两星，完成关卡至少一星。

## 科学边界

前端太阳视黄经采用低阶近似算法，用于互动演示；正式交节时刻、历算与日历发布应以中国科学院紫金山天文台等权威机构发布的历书为准。七十二候是古代物候观察体系，游戏中的现代解释与古代记录分层呈现，不将传统物候直接等同于现代气象、农业或生物学标准。游戏内健康与农事内容不构成专业建议。

详细说明见 `docs/科学与数据来源.md`。
