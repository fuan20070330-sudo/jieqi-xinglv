# 第三方资源与数据来源说明

## 1. 运行依赖

本项目为纯前端作品，运行时仅使用浏览器原生能力：

- HTML5
- CSS3
- 原生 JavaScript
- SVG
- Canvas 2D
- Web Audio API（原创程序化提示音）
- localStorage

**未使用** React、Vue、jQuery、游戏引擎、图表库、动画库、在线字体、图标库或任何第三方运行时依赖。

## 2. 图片与视觉

- 首页四季黄经仪、关卡仪表、星图、按钮、图标、背景纹理均由项目内原创 CSS 和 SVG 生成。
- 成果卡由 Canvas 程序化绘制。
- 无第三方图片、照片、插画、纹理或图标文件。
- 无来源不明的 AI 生成位图。
- 项目图标 `assets/icon.svg` 为本项目原创 SVG。

## 3. 字体

- 不下载、不分发字体文件。
- 使用访问设备已有的系统中文字体回退：
  - 标题优先使用 `Songti SC` / `STSong` / `SimSun` 等衬线字体。
  - 界面优先使用 `PingFang SC` / `Microsoft YaHei` 等无衬线字体。
- 字体渲染效果可能因操作系统不同而略有差异，不影响功能。

## 4. 音乐与音效

- 不包含第三方音乐、录音或音频文件。
- 游戏提示音由 Web Audio API 在浏览器中程序化合成，属于项目原创实现。
- 无外部音频下载、无版权音乐。

## 5. 代码

- 游戏状态机、界面渲染、黄经仪、证据天平、因果链、图鉴、存档与成果卡导出逻辑均由本项目代码实现。
- 未复制来源不明的代码。
- 太阳视黄经近似算法依据公开天文学通用公式背景自行实现；正式历算以权威机构历书为准。

## 6. 节气与物候数据

- 二十四节气名称、顺序和黄经关系：公共领域传统历法知识与公开通行资料。
- 七十二候：以通行本《月令七十二候集解》等公开传统体系为文化背景，项目内说明为原创白话改写。
- 现代气象、天文、生物与物候解释：参考公开科普常识、国家标准方向与权威机构资料。
- 地方习俗：采用“部分地区有……”的地域限定表达。

详细内容与核验清单见 `docs/科学与数据来源.md`。

## 7. 古典诗文

- 使用公共领域古典文学作品。
- 游戏文案中标注作者与篇名。
- 未复制现代出版社注释、译文或排版。
- 正式提交前应由学生逐条核对版本、作者归属与断句。

## 8. 开发测试工具

项目开发与验收使用 Playwright 进行浏览器自动化测试。

- Playwright 仅存在于开发测试环境，不进入游戏运行包。
- 游戏运行时不加载 Playwright 或任何 npm 依赖。
- 单文件离线版经测试未发起网络请求。
- 若参赛提交材料需要说明开发工具，可列出 Playwright 为测试工具，而非作品运行时依赖。

## 9. 数据与隐私

- 无登录、后端、统计埋点、远程 API 与外部 AI 调用。
- 游戏进度保存在访问者浏览器的 localStorage。
- 成果卡在本机 Canvas 生成，不上传。
- 不收集姓名、学校、团队、指导教师、设备身份或位置信息。
