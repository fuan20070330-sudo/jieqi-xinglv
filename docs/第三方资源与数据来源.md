# 第三方资源与数据来源说明

赛事：米兰设计周
赛项主题：触摸时间·魅力节气
类别：C. 数字艺术类——数字游戏作品

## 1. 运行依赖

本项目为纯前端作品，运行时仅使用浏览器原生能力：

- HTML5 Canvas
- CSS3
- 原生 JavaScript
- localStorage
- Web Audio API（原创程序化提示音）

未使用 React、Vue、jQuery、游戏引擎、图表库、动画库、在线字体、图标库或任何第三方运行时依赖。

## 2. 图像与视觉

- 四季地图、地表、河流、树木、花朵、节气碑、角色与天气粒子均由 Canvas 程序化绘制。
- HUD、菜单、季节卡、弹层和触控控件由 CSS 绘制。
- 项目图标为原创 SVG。
- 真实作品截图由浏览器自动截取。
- 未使用第三方图片、照片、插画、纹理或来源不明的 AI 生成位图。

## 3. 字体

- 不下载、不分发字体文件。
- 使用设备已有中文字体回退，如 Microsoft YaHei、Songti SC、STSong、SimSun。
- 不同系统的字体渲染可能略有差异，不影响玩法。

## 4. 音频

- 不使用第三方音乐、录音或音频文件。
- 游戏提示音由 Web Audio API 在浏览器中即时合成。

## 5. 代码

- 世界渲染、角色移动、天气、小游戏状态机、评分与存档均为本项目原创实现。
- 未复制来源不明的代码。
- 开发测试使用 Playwright，不进入游戏运行包。

## 6. 习俗资料

- 节气名称与习俗主题根据公开通行传统文化资料整理。
- 小游戏为习俗主题的简化、艺术化改编，不宣称完整复刻民俗仪式。
- 地方习俗采用地域限定表达，具体来源与核验清单见 `docs/科学与数据来源.md`。

## 7. 数据与隐私

- 无登录、后端、统计埋点、远程 API 或外部 AI 调用。
- 游戏进度保存在访问者浏览器的 localStorage。
- 不收集姓名、学校、团队、指导教师、设备身份或位置信息。
