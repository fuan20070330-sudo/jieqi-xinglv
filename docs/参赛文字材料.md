# 《节气行旅：二十四节气的物候解谜》参赛文字材料

## 一等奖项信息

- 作品名称：《节气行旅：二十四节气的物候解谜》
- 参赛类别：数字游戏作品、VR/AR 软件等数字作品
- 作品形态：浏览器 2D 数字游戏（HTML5 / CSS3 / 原生 JavaScript / SVG / Canvas）
- 运行环境：电脑或手机浏览器；无需登录、后端、外部 AI API、专用硬件

## 1. 作品简介

《节气行旅》是一款以二十四节气与七十二候为知识背景的原创浏览器解谜游戏。玩家扮演节气观察员，进入一座失去秩序的四季时钟，在春、夏、秋、冬四章中修复 24 个节气节点。每个节点都包含“观天、识候、辨误、修复”四个连续操作阶段：玩家先通过太阳视黄经、直射点与昼夜变化校准天文仪器，再从混合候牌中辨认并排序三候，随后用证据辨析一个节气误区，最后接通“太阳位置—昼夜与热量—地表响应—物候表现”的因果链。

作品不是“节气科普长页加积分答题”，而是将节气知识转译为可操作、可失败、可重试、可评分并逐关推进的游戏机制。72 候是可收集图鉴，4 个章末试炼用于检验整章的天文、物候与文化理解。通关后可生成不含身份信息的 PNG“时间行旅”成果卡。

## 2. 创意来源

二十四节气是中国人通过观察太阳周年运动、认识时令与物候变化而形成的时间知识体系。它既有太阳黄经、直射点和昼夜变化这样的天文骨架，也有物候、农事、习俗和诗文构成的生活纹理。创作团队希望解决的问题是：公众能背出节气名称，却常常不清楚节气为何按太阳位置划分，也容易把“节气名称”误当作“当天天气预报”，把古代物候记录误当作现代科学定律。

因此，作品把“时间失序”作为游戏叙事：二十四节气不是资料列表，而是四季时钟上的 24 个故障节点；七十二候不是阅读卡片，而是散落的候牌；科学误区不是附加测验，而是需要被证据天平校正的故障。玩家通过实际修复仪器理解节气。

## 3. 核心玩法

### 观天

每关提供太阳视黄经、直射点和昼夜趋势线索。玩家旋转日轮指针，将绿色观测标记对准目标刻度，再根据节气顺序和天文信息选择节气印。该段训练“节气位置—太阳运动—季节趋势”的对应关系。

### 识候

系统从当前节气与其他节气中混合 6 枚候牌。玩家需找出本节气的三候，再按初候、二候、三候排序。识别成功后，三张候牌收入 72 候图鉴。

### 辨误

每关设有一个科学误区，例如“立春当天全国同步入春”“夏至是全年最热的一天”“霜是从天上落下来的”。玩家需要从四条材料中选择两条正确证据，将证据天平校准。选择错误会进入错题复盘，答对后标记为“已校正”。

### 修复

每关提供四张打乱的事件牌。玩家按“太阳黄经位置 → 太阳直射与昼夜变化 → 地表与大气响应 → 物候表现”排列因果链，完成节气时钟修复。

四个阶段均有明确目标、操作、即时反馈、成功条件是评分影响，避免单纯阅读后点击下一题。

## 4. 章节与推进

- 春章·启蛰：立春、雨水、惊蛰、春分、清明、谷雨。
- 夏章·长明：立夏、小满、芒种、夏至、小暑、大暑。
- 秋章·敛藏：立秋、处暑、白露、秋分、寒露、霜降。
- 冬章·归根：立冬、小雪、大雪、冬至、小寒、大寒。

每章完成 6 个节点后开放章末综合试炼。试炼包含节气星序重连、候牌归位和科学审校三个环节，额外检验本章综合理解，不挤占 24 个节气主线节点。

## 5. 游戏反馈与留存

- 四段式进度、精度百分比、连击数、时轮分与星级。
- 星级阈值：900 分以上三星，760 分以上两星，完成至少一星。
- 章节节点逐关解锁，春夏秋冬按顺序开放。
- 72 候收集度与章末印记。
- 错题进入“证据回廊”，记录命题、正确解释和当时错误选择。
- localStorage 保存最佳成绩、进度、收藏与检查点；刷新后可继续尚未完成的关卡。
- 通关生成“时间行旅”成果卡，可保存为 PNG。

## 6. 科学性与文化表达

作品将知识分为天文历法、古代物候、现代科学解释和生活文化四层：

1. 节气按太阳视黄经每 15° 划分，游戏使用前端低阶太阳视黄经近似算法提供互动演示。
2. 七十二候明确标注为古代观察记录，不直接等同于现代气象或生物学标准。
3. 对露、霜、夏至、入春等在游戏内设置科学辨析，区分天文节点、实际天气和地域差异。
4. 习俗描述使用“部分地区”等限定语；诗句来自公共领域古典文学。
5. 正式历算以中国科学院紫金山天文台等权威历书为准，游戏中的天文结果不作为正式日历发布依据。

## 7. 原创性与差异化

本项目与同一知识主题的科普网页具有明确区别：

- 从“阅读与查询”转为“仪器校准与因果修复”。
- 从“页面章节”转为“可解锁的四季星图”。
- 从“测验正误”转为“精度、连击、星级、收集与章节试炼”。
- 从“知识卡片”转为“72 候候牌收集与因果链操作”。
- 从“成果记录页”转为“通关后由 Canvas 生成的 PNG 行旅卡”。

全部图形优先由 SVG、Canvas、CSS 和程序化生成。项目不使用第三方图片、字体文件、音乐或运行时库；不使用来源不明的代码。

## 8. 可玩性与可访问性

- 桌面和手机均可操作，支持鼠标、触屏与键盘。
- 滑杆支持方向键微调。
- 390px 手机宽度无横向溢出，主要按钮保持触控尺寸。
- 支持 `prefers-reduced-motion` 降低动效。
- 界面兼顾文字、图标、颜色和状态提示。
- 刷新续玩、错误重试、提示扣分，避免玩家被单次错误卡死。

## 9. 科普价值

本作品面向青少年和公众，将“记住节气名称”推进为三层理解：

1. **知道为什么**：节气为什么按太阳黄经划分。
2. **知道怎样辨**：古代物候记录与现代科学解释有什么边界。
3. **知道如何用**：同一节气时刻全国一致，但物候、气候和生活经验具有地域差异。

游戏把传统文化从静态知识转化为可观察、可操作、可纠错的时间秩序，强调尊重传统而不神化传统，使用科学而不把科学简化成单一结论。
