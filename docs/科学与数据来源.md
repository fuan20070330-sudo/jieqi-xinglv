# 科学与文化来源说明

## 1. 内容边界

《节气行旅》以二十四节气习俗作为小游戏主题。节气名称、时间位置与习俗都属于传统文化知识，但二者性质不同：

- 节气是太阳周年视运动的时间划分。
- 习俗是不同地区、不同历史时期形成的生活实践与文化表达。
- 地方习俗不能被表述为全国统一、每天必然发生的自然规律。

游戏使用“部分地区有……”等限定语，将习俗作为文化体验入口，而不是科学证据或天气预报。

## 2. 主要参考方向

- 联合国教科文组织：The Twenty-Four Solar Terms, knowledge in China of time and practices developed through observation of the sun's annual motion（2016 年列入人类非物质文化遗产代表作名录）。
- 中国农业博物馆及公开出版的中国传统节气、农事与民俗资料。
- 中国科学院紫金山天文台等权威机构发布的节气与历法科普资料。
- 公开通行的二十四节气习俗、节令饮食与地方民俗资料。
- 公版古典诗词与传统文化文献。

正式参赛材料中应补充具体网页标题、出版信息和访问日期，并由学生逐条核验。

## 3. 小游戏文化主题

### 春

- 立春：咬春、春饼、萝卜等节令饮食习俗。
- 雨水：部分地区占稻色的农事习俗。
- 惊蛰：蒙鼓皮等象征春雷的习俗。
- 春分：竖蛋的趣味民俗。
- 清明：踏青、放风筝、插柳等春日活动。
- 谷雨：谷雨茶、赏牡丹等春末习俗。

### 夏

- 立夏：斗蛋、称人等习俗。
- 小满：祭车神、农事灌溉等地方传统。
- 芒种：抢收抢种，也有送花神、煮梅等习俗。
- 夏至：夏至面等节令饮食说法。
- 小暑：晒书、晒衣等防潮习俗。
- 大暑：浙江沿海部分地区送大暑船等民俗。

### 秋

- 立秋：晒秋、啃秋等习俗。
- 处暑：放河灯、开渔等地方习俗。
- 白露：收清露、饮白露茶等习俗。
- 秋分：祭月、吃秋菜等传统，与中秋节俗有历史联系。
- 寒露：登高、赏菊等秋日活动。
- 霜降：吃柿子、赏菊、登高等习俗。

### 冬

- 立冬：补冬、吃饺子等习俗。
- 小雪：腌腊肉、晒鱼干等冬储习俗。
- 大雪：赏雪、腌肉、扫雪等冬日生活。
- 冬至：吃饺子、汤圆等节令饮食习俗。
- 小寒：腊八粥、探梅、备年货等习俗。
- 大寒：除尘、备年货等迎年习俗。

## 4. 表现形式说明

- 四季天气（雨、烈日、落叶、雪）属于氛围化艺术表达，不代表每个地区在该节气都会出现相同天气。
- 小游戏对习俗动作进行简化与游戏化改编，不宣称完整复原真实民俗仪式。
- 收集、节奏、时机、分类、行进、顺序记忆等机制均为游戏设计，不构成对传统习俗的科学解释。
- 食物、农事和生活描述不构成专业建议。

## 5. 原创视觉

- 四季地图、角色、节气碑、天气粒子与全部小游戏由 Canvas / CSS 程序化绘制。
- 不使用来源不明的图片、字体文件、音乐、视频或第三方运行时库。
- 系统字体仅作显示回退，不随项目分发。
