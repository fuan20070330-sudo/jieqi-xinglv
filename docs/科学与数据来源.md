# 科学与数据来源说明

## 1. 内容分层

本项目将节气内容分为四层，并在游戏文案中明确区分：

1. **天文历法层**：太阳视黄经、太阳直射点、昼夜趋势、节气顺序。
2. **古代物候层**：七十二候名称与古代观察记录。
3. **现代科学层**：用现代天文学、气象学、物理学与生物学解释现象。
4. **生活文化层**：地方习俗、诗句、农事和生活提示。

古代记录不等于现代科学定论；地方习俗不等于全国统一规律；游戏提示不构成专业农事、医疗或气象预报建议。

## 2. 节气与太阳黄经

二十四节气按太阳周年视运动划分，每 15° 一个节点。本项目采用从立春 315° 起、每个节气增加 15° 的顺序：

- 春分 0°、夏至 90°、秋分 180°、冬至 270°。
- 立春 315°、雨水 330°、惊蛰 345°、清明 15°、谷雨 30°。
- 其余节点按节气序列依次推进。

游戏中的“太阳视黄经”定位用于互动演示和教学比较，不作为正式日历发布依据。

## 3. 前端太阳视黄经近似算法

`js/astro.js` 使用低阶太阳位置近似：

1. 将浏览器 Date 转换为儒略日，并计算 J2000.0 起的儒略世纪数。
2. 计算太阳几何平黄经、平近点角与中心差。
3. 加入章动、光行差的一阶近似修正，得到太阳视黄经。
4. 使用 `sin δ = sin ε · sin λ` 近似太阳赤纬。
5. 用视黄经判断当前节气，并把视黄经值映射到 24 节气刻度盘。

该算法足够支持游戏交互与公众科普演示，但不包含高精度历书所需的全部摄动项。正式交节时刻、日期与历算应以中国科学院紫金山天文台等权威机构发布的历书为准。

参考方法：

- Jean Meeus, *Astronomical Algorithms*, 2nd Edition, 1998. 用于通用低阶太阳位置公式背景。
- 中国科学院紫金山天文台公开发布的历算与节气资料。

## 4. 七十二候

七十二候名称采用公开通行传统体系，每节气三候，共 72 条。游戏内所有候牌说明以“古人的观察记录”开头，避免把传统物候描述直接写成现代生物学定律。

需要注意的边界：

- “鹰化为鸠”“腐草为萤”“雀入大水为蛤”等是古人的观察与想象性解释，不是现代物种转化事实。
- 候应日期存在地域差异和历史版本差异。
- 同一候名在不同文献中的用字可能略有不同，如“候雁北”“鸿雁来”等。
- 游戏采用便于青少年理解的白话改写，正式论文与提交材料应继续核对版本。

传统文献背景：

- 通行本《月令七十二候集解》。
- 二十四节气相关公开非遗资料与农业、物候科普资料。

## 5. 现代科学解释

### 气象季节

项目中的气象学入春、入夏、入秋、入冬说明采用中国气象业务中常见的连续 5 天滑动平均气温判据，并与节气节点区分。不同标准和地区业务可能存在细则差异，提交前应继续核对最新国家标准与地方业务规范。

可核对方向：

- 《气候季节划分》相关国家标准（如 GB/T 42074—2022，具体适用以正式标准文本为准）。
- 中国气象局及地方气象部门公开科普材料。

### 露、霜与凝华

- 露：近地面空气中的水汽在较冷物体表面凝结成液态小水滴。
- 霜：近地面水汽在低温物体表面直接凝华为冰晶。
- 二者都不是从云中降落的降水，也不保证在每个节气当日出现。

### 夏至与世界最热

- 夏至是北半球白昼最长、太阳直射北回归线附近的节点。
- 地表热量收支存在滞后，最高气温常出现在夏至后的三伏时段，因此夏至不一定是最热一天。

### 地球与四季

- 北半球四季主要由地轴倾角、太阳高度和白昼长度变化造成。
- 地球近日点约在北半球冬季前后，不能把北半球夏季炎热简单归因于“离太阳最近”。

## 6. 古典诗句

游戏引用的古典诗文属于公共领域文学作品，均标注作者与篇名。项目未复制现代出版物注释或译文。部分作品的作者归属、异文和断句在学界或版本间可能存在差异，正式提交前应逐条核对权威古籍版本。

## 7. 地方习俗

习俗描述使用“部分地区有……”等限定语，不把地方民俗写成全国统一事实。游戏中的习俗主要用于文化表达，不作为科学证据或生活建议。
