# 人工智能工具使用情况说明

**作品名称：**《节气行旅：二十四节气的物候解谜》

**说明主体：**学生

**赛事：**米兰设计周
**赛项主题：**触摸时间·魅力节气
**作品类别：**C. 数字艺术类——数字游戏作品
**说明范围：**游戏设计、代码、文案、测试与展示材料

## 0. 显著声明

**本作品在代码实现、文案整理、展示版面与测试脚本环节采用了 AI 辅助设计。** AI 不进入游戏运行逻辑，不调用外部 AI API；游戏运行时完全离线、纯前端。学生负责赛项适配、机制决策、科学内容核验、视觉判断、实际测试和最终提交。

## 1. 总体说明

学生在项目中使用了生成式人工智能辅助工具（Codex）参与头脑风暴、代码初稿生成、文案整理、自动化测试脚本编写和汇报材料版式建议。人工智能作为辅助工具使用，不代替学生对作品主题、科学内容、代码质量、原创性和参赛规范负责。

学生负责提出作品方向、确定“数字游戏”形态、设定四段式玩法、审核生成内容、修改不符合要求的部分，并以实际运行结果作为最终验收依据。

## 2. 人工智能参与环节

| 环节 | 人工智能参与内容 | 学生负责内容 |
| --- | --- | --- |
| 概念设计 | 根据学生提出的“四季时钟修复”“观天—识候—辨误—修复”方向，辅助比较关卡机制与反馈方案 | 确定作品定位、C类数字艺术赛道、核心循环、章节结构与不复制既有项目的边界 |
| 游戏代码 | 辅助生成原生 JavaScript 状态机、SVG 黄经仪、Canvas 成果卡、localStorage 存档和响应式 CSS 初稿 | 提出技术要求，检查代码是否符合纯前端约束，运行测试并决定最终保留方案 |
| 节气数据 | 根据公开通行资料结构整理 24 节气与 72 候文本初稿，辅助设计误区与证据 | 核验节气、物候、诗句、习俗和现代科学表述，删除或改写无法确认的内容 |
| 科普文案 | 辅助生成面向青少年的解释、证据链和成果卡文案 | 区分古代记录与现代解释，校对绝对化表述，补充来源和边界说明 |
| 测试 | 辅助编写数据校验、浏览器全流程、错题路径、移动端和离线版测试脚本 | 实际执行测试，检查控制台错误、手机布局、存档与成果卡下载结果 |
| 展示材料 | 辅助整理作品说明、展示海报版面、视频脚本与 PPT 文案结构 | 选择最终截图、核对真实功能、确认不使用虚假数据或身份信息 |

## 3. 人工智能未参与或不应替代的事项

人工智能未被用于生成来源不明的图片、字体、音乐或代码；未调用外部 AI API；游戏运行时不依赖人工智能服务。人工智能工具不代替学生进行以下工作：

- 对传统物候、诗句、习俗和科学解释作最终事实核验。
- 判断作品是否符合赛事对原创性、匿名化和提交格式的具体要求。
- 代替学生在真实设备上试玩并作出审美、难度和可玩性判断。
- 对专业农事、健康或气象内容作专业背书。

## 4. 学生修改与验收工作

学生在提交前应完成以下验收，并可根据实际完成情况在本文件末尾补充记录：

1. **玩法验收**：完整游玩 24 个节气关与 4 个章末试炼，确认每段都有目标、操作、反馈、成功条件和评分。
2. **科学性验收**：逐条检查 72 候、24 组误区证据、诗句与传统习俗，修改无法确认或绝对化的表述。
3. **技术验收**：确认真实浏览器中无控制台错误、无横向溢出，手机触控可用，刷新可续玩，成果卡可下载。
4. **离线验收**：直接打开单文件离线版，确认无网络请求且核心玩法可运行。
5. **原创性验收**：确认页面结构、交互模型、视觉与代码未复制其他作品；核验第三方资源说明。
6. **匿名化验收**：检查界面、截图、PPT、视频和文档不出现学校、团队成员、指导教师等身份信息。
7. **材料验收**：确认截图来自真实作品，PPT 与视频中的功能、数据和结论与最终版本一致。
