# 《节气行旅》评审演示脚本与录屏方案

> 本视频为 C 类数字游戏作品的评审辅助演示，不作为 D 类短视频赛道作品提交。

## 1. 建议规格

- 3—5 分钟，16:9，1920 × 1080。
- 真实运行画面，不加入水印、LOGO、个人信息。
- 可配中文字幕，背景音乐使用无版权素材或游戏原声。
- 前半段以桌面端展示探索和天气，后半段展示手机端与不同小游戏。

## 2. 分镜

### 00:00—00:20 开场

画面：夏日平原的卡通村庄，镜头随着小人移动，麦田闪光，云朵飘动。字幕：触摸时间 · 魅力节气。

旁白：“如果节气不是一页文字，而是一段可以走进去的时间，它会是什么样子？《节气行旅》让玩家走进四季，用移动和小游戏触碰节气习俗。”

### 00:20—00:45 四季地图

画面：切换春、夏、秋、冬四张地图。展示春的雨、夏的烈阳、秋的落叶、冬的雪。

旁白：“作品分为春夏秋冬四个篇章。每个季节都有自己的色彩、天气、声音和六个节气碑。”

### 00:45—01:20 角色移动与互动

画面：用 WASD 控制小人穿过田野，靠近节气碑，画面出现互动提示，按键进入小游戏。

旁白：“玩家可以用 WASD 或方向键移动，手机端使用虚拟摇杆。靠近节气碑后，按 E 或互动按钮进入习俗小游戏。”

### 01:20—02:15 小游戏展示

画面：展示至少三个小游戏：立春咬春、春分立蛋、清明放纸鸢。

旁白：“立春要接住咬春食材，春分要在合适时机让鸡蛋站稳，清明要操控纸鸢穿过柳梢。不同节气对应不同的手势和操作。”

### 02:15—02:50 章节与反馈

画面：完成一关、获得星星、章节完成、进入下一季。

旁白：“每完成一个节气碑，就会获得星级和成绩。完成一季的六个节气碑后，季节之门才会打开。”

### 02:50—03:15 手机端

画面：390px 竖屏手机，展示虚拟摇杆、节气碑互动与一个小游戏。

旁白：“手机端保留完整的移动、互动和小游戏体验，并针对触屏控制做了适配。”

### 03:15—03:40 收束

画面：展示四季通关画面、作品名与一句话定位。

旁白：“《节气行旅》从节器物象走向时间经验，让玩家用行走和游戏，重新理解季节如何改变生活。”

## 3. 录屏准备

- 使用最新版在线页面或本地静态服务器。
- 清除 localStorage 测试存档，确保从头开始。
- 桌面端至少录制春、夏、秋、冬各一个镜头。
- 录制至少三个不同小游戏，避免只展示收集类。
- 手机端录制摇杆移动和一次进入小游戏。
- 隐藏书签栏、通知、账号昵称和窗口标题中的个人信息。
