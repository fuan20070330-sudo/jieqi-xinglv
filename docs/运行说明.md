# 运行环境与操作说明

- 赛事：米兰设计周
- 赛项主题：触摸时间·魅力节气
- 类别：C. 数字艺术类——数字游戏作品
- 在线演示：https://fuan20070330-sudo.github.io/jieqi-xinglv/

## 1. 作品形态

- 纯前端俯视角 2D 数字游戏。
- 技术：HTML5 Canvas、CSS3、原生 JavaScript、localStorage。
- 不使用登录、后端、数据库、外部 AI API、专用硬件或第三方运行时库。
- 核心玩法可离线运行。

## 2. 推荐环境

- 桌面：Chrome / Edge 最新稳定版，1280 × 720 及以上。
- 手机：Android / iOS 主流现代浏览器，390 × 844 已验证。
- 项目在 Chrome 155 下完成自动化验收。

## 3. 启动方式

### 目录版

直接打开 `index.html`，或启动本地服务器：

```powershell
py -m http.server 8770 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8770/`。

### 单文件离线版

直接双击：

```text
output/节气行旅_离线版.html
```

重新构建：

```powershell
node build-offline.mjs
```

## 4. 操作

### 场景移动

- 键盘：WASD 或方向键。
- 手机：拖动左下角虚拟摇杆。
- 角色可在地图边界内自由行走。

### 节气碑与星门

- 靠近节气碑时，底部提示显示“行 / 入”；桌面按 E 或空格，手机点右下角按钮。
- 靠近每季地图右侧的“往”星门时，手机按钮变为“往”，桌面也可以直接点击底部提示。
- 星门需要本季 6 个节气碑全部完成，并且本季星数至少 13 / 18。
- 未满足条件时会显示还差几个节气碑或几颗星。

### 小游戏

- 进入小游戏后先显示三步教程与目标。
- 教程阶段不会计时，也不会响应画布操作。
- 点击“确定，开始”，或按空格 / Enter，才正式进入挑战。
- 鼠标、触屏、键盘均可完成对应操作；具体手势见每关教程。

24 种机制包括：接取、顺序记忆、节拍、时机、拖拽拼装、分类、斗蛋瞄准、交替踩踏、拖放插秧、路径描线、天气反应、左右行进、分类挂晒、水流操舵、点选收集、旋转校准、顺序登阶、摇动采摘、折合、覆盖涂抹、清扫、画圈搓圆、按序投料、快速扫尘。

## 5. 星级与存档

- 无失误 3 星；失误不超过 2 次为 2 星；其他完成情况为 1 星。
- 每关只保存历史最佳星级和最佳成绩，重玩不累加。
- 每季 18 星，严格超过 2/3 即至少 13 星，才能通过“往”星门。
- localStorage 键名：`jieqi-journey-save-v2`。
- 保存完成状态、最佳星级、最佳成绩、当前季节、章节庆祝状态和声音设置。
- 刷新页面后可继续；清除浏览器站点数据会重置进度。

## 6. 天气与四季

- 春：斜雨与花瓣。
- 夏：烈日、光芒与热浪微粒。
- 秋：旋转落叶与金色场景。
- 冬：多层飘雪与结冰水面。
