# 运行环境与操作说明

- 赛事：米兰设计周
- 赛项主题：触摸时间·魅力节气
- 类别：C. 数字艺术类——数字游戏作品
- 在线演示：https://fuan20070330-sudo.github.io/jieqi-xinglv/

## 1. 作品形态

- 纯前端浏览器 2D 数字游戏。
- 技术：HTML5、CSS3、原生 JavaScript、SVG、Canvas。
- 不使用登录、后端、数据库、外部 AI API、专用硬件或第三方运行时库。
- 运行时核心功能可离线。

## 2. 推荐环境

- 桌面：Chrome / Edge 最新稳定版，1280 × 720 及以上。
- 手机：Android / iOS 主流浏览器，360px 及以上宽度。
- 本项目在 Chrome 155、390 × 844 和 1440 × 1100 视口下完成自动化验收。
- 使用 CSS `color-mix()`、Canvas、Web Audio 等现代浏览器能力；过旧浏览器可能出现样式降级。

## 3. 目录版运行

### 直接打开

双击 `index.html`。

### 推荐本地服务器

在项目目录执行：

```powershell
py -m http.server 8770 --bind 127.0.0.1
```

访问：

```text
http://127.0.0.1:8770/
```

项目不依赖 CDN，不需要 npm 安装。

## 4. 单文件离线版

直接双击：

```text
output/节气行旅_离线版.html
```

该文件已内联全部 CSS、数据、算法和游戏脚本，不发起网络请求。重新构建：

```powershell
node build-offline.mjs
```

## 5. 操作方式

### 观天

- 鼠标：拖动滑杆或点击 `− / ＋`。
- 触屏：拖动滑杆或点击加减按钮。
- 键盘：聚焦滑杆后使用左右方向键。
- 对齐后点击“锁定黄经”，再选择正确节气印。

### 识候

- 点击 6 枚候牌中的 3 枚。
- 点击“确认三候”。
- 依次点击正确候牌，填入初候、二候、三候槽。

### 辨误

- 点击 4 张材料中的 2 张。
- 点击“校准天平”。
- 错误会写入“证据回廊”，答对后记录标记为“已校正”。

### 修复

- 依次点击 4 张事件牌。
- 可“清空重排”。
- 点击“启动时轮”完成本关。

## 6. 存档

- 存储位置：浏览器 localStorage。
- 键名：`jieqi-xinglv-save-v1`。
- 保存内容：关卡最佳成绩、星级、连击、72 候收集、试炼、错题、声音设置、未完成关卡检查点。
- 刷新页面后，首页“继续行旅”会从上一个完成阶段继续。
- 清除浏览器站点数据会删除存档。
- 游戏内“玩法说明 → 清除全部进度”也可重置存档。

## 7. 隐私

- 无登录、无上传、无统计埋点、无外部 AI 调用。
- 不收集姓名、学校、设备身份或位置。
- 成果卡仅使用本地游戏成绩与完成日期，不包含个人身份信息。

## 8. 测试命令

### 静态测试

```powershell
node tests/run-tests.mjs
```

检查：

- 24 节气数量、顺序和黄经。
- 72 候完整性与唯一性。
- 每关节气数据、证据与因果链。
- 4 个章末试炼。
- 太阳黄经在二分二至附近的近似精度。
- HTML 无远程运行时依赖。

### 浏览器全流程测试

先启动本地服务器，再执行：

```powershell
$env:NODE_PATH="<Playwright 所在 node_modules>"
node tests/browser-smoke.cjs
```

检查：

- 24 个节气完整通关。
- 4 个章末试炼完整通关。
- 72 候全部收集。
- 刷新续玩。
- 成果卡 PNG 下载。
- 桌面与 390px 手机无横向溢出。
- 控制台无错误。

### 错题路径测试

```powershell
node tests/wrong-path.cjs
```

检查提示扣分、错误记录、证据复盘与“已校正”状态。

### 离线版测试

```powershell
node tests/offline-smoke.cjs
```

检查单文件版启动、关卡进入、无网络请求和控制台错误。
