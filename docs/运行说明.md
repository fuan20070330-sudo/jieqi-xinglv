# 运行环境与操作说明

- 赛事：米兰设计周
- 赛项主题：触摸时间·魅力节气
- 类别：C. 数字艺术类——数字游戏作品
- 在线演示：https://fuan20070330-sudo.github.io/jieqi-xinglv/

## 1. 作品形态

- 纯前端俯视角 2D 数字游戏。
- 技术：HTML5 Canvas、CSS3、原生 JavaScript、localStorage。
- 不使用登录、后端、数据库、外部 AI API、专用硬件或第三方运行时库。
- 核心玩法可离线运行。

## 2. 推荐环境

- 桌面：Chrome / Edge 最新稳定版，1280 × 720 及以上。
- 手机：Android / iOS 主流现代浏览器，390 × 844 已验证。
- 项目在 Chrome 155 下完成自动化验收。

## 3. 启动方式

### 目录版

直接打开 `index.html`，或启动本地服务器：

```powershell
py -m http.server 8770 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8770/`。

### 单文件离线版

直接双击：

```text
output/节气行旅_离线版.html
```

重新构建：

```powershell
node build-offline.mjs
```

## 4. 操作

### 场景移动

- 键盘：WASD 或方向键。
- 手机：拖动左下角虚拟摇杆。
- 角色可在地图边界内自由行走。

### 节气互动

- 靠近发光的节气碑时，底部会出现互动提示。
- 桌面按 E 或空格；手机点击右下角“行”按钮。
- 进入对应习俗小游戏。

### 小游戏操作

- **收集**：左右移动篮子，接住目标物。
- **节奏**：节拍环接近时点击画面或按空格。
- **时机**：游标进入绿色区域时点击或按空格。
- **分类**：点击对应分类按钮，键盘也可使用数字键。
- **行进**：左右移动纸鸢、河灯或船只，避开障碍。
- **顺序记忆**：观看高亮顺序，再按同样顺序点击符号。

## 5. 存档

- localStorage 键名：`jieqi-journey-save-v2`。
- 保存每个节气碑的完成状态、星级、最佳成绩、当前季节和章节庆祝状态。
- 刷新页面后可继续；清除浏览器站点数据会重置进度。
- 通关画面的“再走一遍”会重新开始四季进度。

## 6. 天气与四季

- 春：斜雨与花瓣。
- 夏：烈日、光芒与热浪微粒。
- 秋：旋转落叶与金色场景。
- 冬：多层飘雪与结冰水面。
